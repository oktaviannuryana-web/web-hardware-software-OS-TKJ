01 / Gambaran besar

TKJ adalah ilmu yang membuat teknologi bekerja.

Teknik Komputer dan Jaringan (TKJ) mempelajari cara merakit, memasang, mengatur, merawat, dan memperbaiki komputer serta jaringan. Agar mudah dipahami, bayangkan komputer seperti sebuah tim: hardware adalah tubuhnya, software adalah instruksinya, dan sistem operasi adalah koordinator yang mengatur semuanya.

  • Hardware bisa disentuh dan menjadi tempat proses berlangsung.
  • Software berisi perintah agar komputer melakukan tugas tertentu.
  • OS menjembatani pengguna, software, dan hardware.
02 / Hardware

Perangkat keras yang membentuk komputer.

Hardware adalah bagian fisik komputer yang dapat dilihat dan disentuh. Setiap komponen memiliki tugas berbeda, tetapi semuanya saling mendukung.

H / 01

Pengertian

Hardware adalah komponen fisik seperti CPU, RAM, motherboard, monitor, keyboard, dan kabel jaringan.

Contoh
CPU, RAM, SSD, motherboard, monitor, NIC.
Penggunaan
Merakit PC, upgrade performa, instalasi jaringan, dan perawatan lab.
Lebih
Bisa diukur, diganti, dan ditingkatkan sesuai kebutuhan.
Kurang
Bisa rusak, membutuhkan listrik, dan biaya pengadaan atau upgrade.
H / 02

Komponen penting

Kenali tugas komponen sebelum merakit agar tidak salah memilih atau memasang.

CPU
Memproses instruksi dan perhitungan.
RAM
Menyimpan data sementara saat program berjalan.
Storage
Menyimpan OS, aplikasi, dan file secara permanen.
NIC
Menghubungkan komputer ke jaringan kabel atau nirkabel.
03 / Software

Perintah digital untuk menyelesaikan pekerjaan.

Software tidak memiliki bentuk fisik. Ia tersimpan di media penyimpanan dan berjalan menggunakan hardware.

01

Software sistem

Contohnya Windows, Linux, driver, dan utilitas. Tugasnya mengatur sumber daya komputer agar hardware dapat digunakan.

02

Software aplikasi

Contohnya browser, pengolah dokumen, desain, dan aplikasi konfigurasi jaringan untuk kebutuhan pengguna.

03

Software pemrograman

Contohnya editor kode, compiler, dan interpreter yang membantu membuat aplikasi atau automasi.

Kelebihan & kekurangan

Kelebihan: mudah diperbarui, dapat disalin atau dipasang di banyak perangkat, dan membantu pekerjaan menjadi cepat.

Kekurangan: bisa terkena malware, membutuhkan kompatibilitas dengan OS atau hardware, dan sebagian software berbayar.

$ install --purpose=tkj
> browser: research
> wireshark: analyze
> editor: configure
04 / Operating system

OS adalah pengatur utama komputer.

Sistem operasi mengelola CPU, memori, file, perangkat input-output, keamanan, dan aplikasi sehingga pengguna tidak perlu mengatur hardware secara langsung.

DESKTOP / LAPTOP

Windows

Cocok untuk pembelajaran umum, kantor, multimedia, dan gaming karena dukungan aplikasinya luas.

PlusMudah digunakan, driver dan aplikasi sangat banyak.
MinusLisensi dapat berbayar dan sering menjadi target malware.
SERVER / OPEN SOURCE

Linux

Banyak digunakan untuk server, praktik jaringan, pemrograman, dan komputer dengan spesifikasi terbatas.

PlusGratis, ringan, aman, fleksibel, dan dapat dikustomisasi.
MinusPerlu adaptasi terminal dan tidak semua aplikasi tersedia.
APPLE ECOSYSTEM

macOS

OS untuk komputer Apple dengan integrasi perangkat dan pengalaman pengguna yang konsisten.

PlusStabil, rapi, aman, dan terintegrasi dengan perangkat Apple.
MinusHarga perangkat tinggi dan pilihan upgrade lebih terbatas.
Fungsi OS yang wajib diingat: mengelola proses, memori, file, perangkat, keamanan, jaringan, dan menyediakan antarmuka agar pengguna dapat menjalankan aplikasi.
